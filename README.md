# Binbows OS

**Binbows** is a monolithic kernel operating system built from scratch with performance, learning, and extensibility in mind.

> Started this project when I was 13 — and yes, I’m still 13 as I write this

---

## Current Features

### Limine bootloader
### PCI scanning and writing
### IDE R/W
### A very crappy shell
### Framebuffer
### Fat12/16/32
### PC speaker
### Buddy allocator
### PIT timer

## Planned features

### NTFS and EXT/2/3/4
### UHCI
### AHCI
### and whatever else an os needs
